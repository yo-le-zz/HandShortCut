# HandShortCut v1.1.0

Créé par **yolezz**. Les actions deviennent de vrais **workflows**, et les gestes gagnent les **deux mains**,
les **doigts levés**, le **comptage** et le **dessin dans l'air**.

## Points forts
- **Workflows en graphe** avec liens, branches, boucles, ports d'erreur, et **données partagées** (`{{ nom }}`).
- **Dessine un chiffre ou une forme** dans l'air : reconnu en local (ou par ton IA), passé en argument.
- **Conditions système** : uptime, CPU, température, RAM, batterie, heure, processus…
- **Retour visuel** : bulles, notification du bureau, page Activité détaillée.
- **Import Windows ↔ Linux automatique**, 20 modèles prêts à installer.
