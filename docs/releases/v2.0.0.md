# PhysicalShortCut v2.0.0

Créé par **yolezz**. **HandShortCut devient PhysicalShortCut** : la main n'est plus qu'un déclencheur parmi d'autres.

## Points forts
- **Son** (claquements), **voix** (hors ligne), **empreinte**, **USB / Bluetooth / secteur / capot / Wi-Fi**.
- **Capteurs** : lumière, secousse, températures, ventilateur, inactivité, et **capteurs externes** (Arduino/ESP32) pour le gaz, l'humidité, le mouvement…
- **Micro désactivé par défaut**, rien n'est enregistré ni envoyé.
- Tes données et tes réglages de la 1.x sont repris automatiquement. Voir [RENAMING.md](../../RENAMING.md).

## Téléchargements
| Système | Fichier |
