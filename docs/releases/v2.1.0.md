# PhysicalShortCut v2.1.0

Créé par **yolezz**.

## Points forts
- **Éditeur de workflows** : grand canvas, **zoom** (molette) et **déplacement** en glissant dans le vide.
- **21 nouvelles étapes** : hostname, état de la musique, volume, IP, date, écrans… ; conditions (comparer, switch, au hasard, attendre jusqu'à) ; boucles (tant que, de A à B, N fois, sortir, tour suivant).
- **Le 5** dessiné dans l'air est bien mieux reconnu (7 façons de l'écrire).
