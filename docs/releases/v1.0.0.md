# HandShortCut v1.0.0

Première version publique : pilote ton ordinateur avec des gestes de la main, via la webcam,
sur **Windows** et **Linux**.

## Points forts
- **45 types d'étapes** en 7 catégories, avec icônes, descriptions et exemples.
- **Éditeur d'actions** avec glisser-déposer pour changer l'ordre d'exécution.
- **Gestes modifiables** (nom, action, seuil, tenue, pause, ré-enregistrement) et durées affichées en **secondes et millisecondes**.
- **Interface refaite**, hors ligne, avec de vraies icônes.
- **Compatibilité Linux ↔ Windows** : alias de touches, chemins portables, export / import, `doctor`, `autostart`.
- **Paquets** : `.deb`, `.rpm`, `.exe` (Inno Setup) et `.msi` (WiX), avec icône dans le menu d'applications.

## Téléchargements
| Système | Fichier |
|---|---|

| Fedora / RHEL | `handshortcut-1.0.0-1.x86_64.rpm` |
| Windows | `HandShortCut-1.0.0-x64.msi` ou `HandShortCut-Setup-1.0.0.exe` |
